# AGENTS.md

## Project

This is a hackathon frontend template built with React, Vite, TypeScript, and Bun.

## Commands

- Install: `bun install`
- Dev server: `bun run dev`
- Build: `bun run build`
- Lint: `bun run lint`
- Generate API client: `bun run generate-client`

## Codebase

- `src/main.tsx` creates the React app, configures the OpenAPI client base URL from `VITE_API_URL`, attaches the auth token, and mounts TanStack Router.
- `src/routes` contains file-based TanStack Router routes. Public auth pages are `login` and `signup`; protected app pages live under `_layout`.
- `src/routeTree.gen.ts` is generated by TanStack Router. Do not hand-edit it unless you are fixing route generation fallout.
- `src/client` is generated by `@hey-api/openapi-ts` from the backend OpenAPI schema. Prefer regenerating it over manual edits.
- `src/hooks/useAuth.ts` owns login, signup, logout, current user lookup, and token persistence.
- `src/components/UserSettings` contains profile update, logged-in password change, and account deletion UI.
- `src/components/Admin` contains admin user management UI.
- `src/components/Items` contains the sample CRUD resource. Treat it as replaceable starter code for real project entities.
- `src/components/ui` contains reusable shadcn-style UI primitives. Keep changes compatible with existing component patterns.
- `public` contains static assets served by Vite.

## Rules

- Use Bun. Do not add npm, pnpm, or yarn lockfiles.
- Keep this as a frontend-only project at the repository root.
- Do not add Docker, Nginx, Compose, Traefik, or frontend server deployment files.
- Deploy the frontend with Cloudflare Pages.
- Manage the API base URL with `VITE_API_URL`; do not hardcode backend URLs in source code.
- Keep `src/client` as generated OpenAPI client code.
- Do not add password recovery, reset password email, test email, or mailcatcher UI/code.
- Keep logged-in password change functionality.

## Backend Defaults

- Local API: `http://localhost:8000`
- OpenAPI JSON: `http://localhost:8000/api/v1/openapi.json`
- Local frontend: `http://localhost:5173`
